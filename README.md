# Barracuda

Barracuda es un archivo musical independiente dedicado a discos, artistas e historias que siguen resonando. El sitio fue desarrollado como proyecto final del curso de Desarrollo Web de Coderhouse.

## Sitio publicado

[Ver Barracuda en Vercel](https://barracuda-seven.vercel.app/index.html)

## Páginas

- **Inicio:** presentación editorial y selección de discos.
- **Proyecto:** historia y propósito de Barracuda.
- **Destacados:** selección mensual de artistas y álbumes.
- **Contacto:** formulario para recomendaciones y colaboraciones.
- **Archivo:** catálogo musical con filtrado por género.

## Tecnologías

- HTML5 semántico.
- SCSS con variables, mixins, nesting, `@extend` y partials.
- Bootstrap 5 para la navegación responsive.
- JavaScript para el filtrado del archivo.
- Vercel para el despliegue.
- Cosmos para busqueda de imagenes
- Photopea para diseño del logo

## Desarrollo local

El proyecto es estático. Puede abrirse `index.html` directamente o ejecutarse con un servidor local.

Para recompilar los estilos después de modificar SCSS:

```bash
sass scss/main.scss styles/styles.css --style=expanded --source-map
```
